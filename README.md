# Mirror Pool Scout 🔮 (Alpha / Work in Progress)

**Mirror Pool Scout** is a Chrome extension currently in active development, built for Magic: The Gathering traders, competitive players, and procurement hunters. It aims to transform manual decklist sourcing into an automated, visual dashboard directly in your browser.

## Current Status
🚧 **This project is currently in early Alpha.** The core UI and local database features are actively being built and refined. An official packaged release will eventually be available via Gumroad once development hits version 1.0.

## The Developer Behind the Tool

## Planned Features
* **Live Market Procurement:** Custom UI overlay injected into marketplace listings for one-click card tracking.
* **Intelligent Decklist Parsing:** Paste any MTG decklist to instantly generate a targeted, visual procurement grid.
* **Financial Tracking:** Monitor your market floor, total spent, and net variance in real time.
* **Data Sovereignty:** All watchlist and financial data is stored securely offline in your browser's local storage.
